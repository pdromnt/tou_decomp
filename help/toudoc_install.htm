2.0 Installation

Download the release archive for your operating system and architecture, then extract it completely. Run TOU.exe on Windows, TOU on Linux, or TOU.app on macOS. Keep the program with its packaged data, level, music, sound, ship, and help directories.

TOU saves modern settings in settings.json beside its assets. In a macOS package this is inside TOU.app/Contents/Resources.

2.1 System Requirements

Use the package matching your platform:

  • Windows x86, x64, or ARM64
  • Linux x64 or ARM64
  • macOS Intel or Apple Silicon

The game uses SDL3 and SDL_mixer, which are included in release builds. Windows releases do not require separate SDL DLLs or the Visual C++ redistributable.

2.2 TOU doesn't run well on my machine. What to do?

Try these options before reporting a performance problem:

  1. Under Options / Details & Visuals, lower the resolution or use Windowed mode.
  2. Reduce or disable running water, waves, parallax, particles, shadows, or line of sight.
  3. Reduce the number of computer pilots. Large 64-player matches intentionally put much more load on the simulation.
  4. If the problem persists, report your operating system, architecture, selected level, player count, and exact steps.
