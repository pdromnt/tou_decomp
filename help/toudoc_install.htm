2.0 Installation

Download the release archive for your operating system and architecture, then extract it completely. Run TOU.exe on Windows, TOU on Linux, or TOU.app on macOS. Keep the program with its packaged data, level, music, sound, ship, and help directories.

TOU saves modern settings in settings.json beside its assets. In a macOS package this is inside TOU.app/Contents/Resources.

2.1 System Requirements

Use the package matching your platform:

  • Windows x86, x64, or ARM64
  • Linux x64 or ARM64
  • macOS Intel or Apple Silicon

The game uses SDL3 and SDL_mixer, which are included in release builds. Windows releases do not require separate SDL DLLs or the Visual C++ redistributable.

Display scaling and beta shader effects are selected under Options / Details & Visuals / Display and Rendering Settings. No launch flags are needed. Compatible shader presentation is detected automatically; systems without it use SDL presentation, with Pixel art instead of FSR and no added shader effects.

2.2 TOU doesn't run well on my machine. What to do?

Try these options before reporting a performance problem:

  1. Under Options / Details & Visuals, lower the resolution or use Windowed mode.
  2. In Display and Rendering Settings, turn off Shader effects (beta) and choose Pixel art, Smooth, or Crisp instead of FSR.
  3. On Raspberry Pi / Compute Module systems, try an X11 desktop session. CM4 testing on Debian found severe performance and match audio problems under Wayland, not the audio sample settings.
  4. Reduce or disable running water, waves, parallax, particles, shadows, or line of sight.
  5. Reduce the number of computer pilots. Large 64-player matches intentionally put much more load on the simulation.
  6. If the problem persists, report your operating system, architecture, selected level, player count, and exact steps.
